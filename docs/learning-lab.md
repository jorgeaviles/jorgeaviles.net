# Learning Lab

The Lab is one React island in a static Astro page. It teaches a single independently
synthetic ranch-profitability question through three hash-linked lessons: predicting
a dollar profit, predicting profitability, and testing predictions. Default models
are fitted; visitors can immediately change inputs. Optional disclosures retain
actual gradient training and technical detail.

See [the ranch architecture and verification record](ranch-learning-lab.md) for
synthetic assumptions, features, 72/18 partitioning, five independent fold fits,
fold-local scaling, final-test locking, numerical tests and review evidence.

No real agency or published-study data, external model service, application server,
charting library, tracking or persistence is used. The educational example is linked
to the Research page as a related question, not a reproduction of its methods or
results. Resetting restarts a deterministic demonstration, not an independent
real-world performance study.

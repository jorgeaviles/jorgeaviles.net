# Learning lab implementation

The three stages share one React island at `/lab/`. Pure TypeScript in `src/lib/ml/models.ts` owns deterministic synthetic generation, fixed 54/18/18 classification partitions, training-only standardization, models, batch gradients, stable objectives, rankings and evaluation. The regression fixture contains 24 noisy synthetic task observations. No service, ML runtime or chart dependency is added.

Linear regression minimizes mean squared residuals, with gradients including the factor of two. Its displayed weight acts on standardized complexity; the inspector also gives slope and intercept in original units. Logistic regression minimizes mean `max(z,0) - yz + log1p(exp(-abs(z)))`, avoiding logarithms of saturated probabilities. Gradients use mean `(sigmoid(z)-y)x`; bias omits x. Parameter updates are bounded to ±100. Learning rates are small fixed presets, not a convergence guarantee.

One authoritative logistic model drives training, validation loss, the decision boundary and evaluation ranking. SVG boundary geometry solves `w·standardized(x)+b=0`, corresponding to probability 0.5. At zero weights there is no unique line. The probability estimates have not been assessed for calibration. Training uses one batch update per 100ms timer and pauses on lesson changes. No animation starts automatically. Manual edits pause training and clear the recent-loss trace.

Evaluation uses only validation records. Threshold is inclusive; top-K ties use record ID. Precision and recall return null when their denominators vanish and the interface says Undefined. Policy changes never update model parameters. Final test disclosure locks training and policies until reset. Repeated reset/test inspection is explicitly described as tuning, not unbiased assessment. Models and controls remain educational; this synthetic sample establishes no real operational performance.

Controls and the full ranked set share the primary panel. Record tables and mathematics are expandable. Native buttons, labels, selectors and inputs provide keyboard alternatives to visual inspection; point shapes redundantly encode labels. The server-rendered initial lesson and noscript explanation remain useful without JavaScript. On mobile the controls stack below the primary chart; the evaluation slider and ranked cards remain together.

Validation: finite-difference checks cover every model weight and bias, loss reduction, deterministic replay, data/partition isolation, stable BCE, saturation, confusion counts, undefined metrics, threshold equality, K boundaries and stable ties. Browser journeys cover learning, pause/reset, example selection, policies, record disclosure, final-test lock and no-JavaScript reading. Screenshots and exact final results are recorded in the implementation handoff. Existing production verification notes describe the prior deployed reference release; this feature requires review and is not deployed automatically from its branch.

## Feature verification

The feature replaces the obsolete fixed-ranking component and its tests with numerical model tests. Nine numerical tests include parameterized finite-difference checks for every weight and bias, training replay/loss reduction, isolation and stable policy metrics. The browser matrix has 156 checks across Chromium desktop/laptop/mobile and WebKit desktop/tablet/mobile, with reduced-motion preference on the laptop profile. No dependencies were added.

The full `npm run verify` passes type/content checks, lint, formatting, numerical tests, draft-publication regression, static build/link/privacy checks and browser/accessibility journeys. Screenshot review covers all three lessons at desktop, laptop and mobile widths; local captures are ignored under `.local/learning-lab/`. Initial review found and corrected ranked-card accessible naming and separated policy selection from inspected-record highlighting. Existing `NO_COLOR`/`FORCE_COLOR` environment warnings are non-failing. No production deployment or DNS/account change is part of this feature.

Limits: two simple synthetic fixtures, one-feature regression and two-feature linear classification; uncalibrated probability estimates; fixed axes may clip extreme manual predictions; small synthetic test results cannot establish operational generalization. The final-test lock discourages iterative test tuning but is not a security boundary, and repeated experiment resets do not make repeated test inspection unbiased.

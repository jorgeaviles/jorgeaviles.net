[Cloudflare Web Analytics](https://developers.cloudflare.com/web-analytics/about/)
uses a browser beacon on the public site to measure page visits and loading
performance. Cloudflare provides these measurements without tracking individual
visitors across its customers’ websites.

The Lab runs its data, calculations, sliders, and model results locally in your
browser. Contact links open your email application or an external professional
profile.

<h2 id="portfolio-assistant-privacy">Portfolio assistant</h2>

Submitting a question sends its text and relevant public portfolio passages to a
separate Cloudflare Worker and Workers AI. Use the assistant for questions about
published projects, experience, and research, keeping personal, confidential, and
agency information private.

Each question stands alone. The site retains no conversation history in browser
storage or application logs, and questions stay separate from Web Analytics
measurements. The Worker uses the connecting IP address transiently for request
throttling; that address stays outside the AI prompt. Cloudflare processes
requests and operational metadata under its own policies; see
[Workers AI data usage](https://developers.cloudflare.com/workers-ai/platform/data-usage/).

Answers present AI summaries or selected source passages with links to the
original pages. Review those pages for full context and to check the answer’s
accuracy. The [case studies](/work/), [background](/about/), and
[research pages](/research/) are also available for direct exploration.

<h2 id="portfolio-mcp-privacy">Public MCP integration</h2>

Compatible AI applications use the read-only MCP endpoint to retrieve curated
public portfolio passages and original source URLs. The connecting application
handles interpretation; the endpoint handles retrieval.

The service uses the connecting IP address transiently for throttling and retains
no conversation history or application request-content logs. Cloudflare processes
network requests and operational metadata. Your connected AI application follows
its own data practices. Use public portfolio questions and keep confidential
information private. See [connection instructions](/mcp/).
